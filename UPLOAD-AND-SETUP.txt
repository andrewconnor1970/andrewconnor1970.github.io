UPLOAD
Upload the CONTENTS of this package to the repository root, preserving folders. Replace matching HTML and CSS files. Unchanged existing downloads and assets remain in place.

CLOUDFLARE WEB ANALYTICS - ONE ACCOUNT-SPECIFIC STEP
1. In Cloudflare, open Web Analytics and add tiamat.au as a site.
2. Copy the JS snippet from Manage site.
3. In each HTML file, paste that snippet immediately before the comment that begins: Cloudflare Web Analytics.
4. Commit the changed pages.

The exact snippet cannot be prefilled because Cloudflare generates a site-specific token. Do not publish a guessed or placeholder token.

GOOGLE SEARCH CONSOLE
1. Add or open the tiamat.au property in Google Search Console and complete Google's ownership verification if requested.
2. Open the Sitemaps report.
3. Submit: sitemap.xml
4. Confirm that its status becomes Success.
5. Use URL Inspection for the homepage and Stories page if you want to request initial indexing explicitly.

SOCIAL PREVIEWS
The pages reference the existing assets/images/tiamat-hero.webp for general previews. Stories and Artwork use the included Else artwork. Social networks may cache older previews; the metadata in this release is the authoritative current version.

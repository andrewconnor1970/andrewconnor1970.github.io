# Tiamat.au

Source files for Andrew Connor and Else's creative website.

## Local test

Open `index.html` in a browser and keep the folder structure intact.

## Publishing

Upload the contents of this release to the root of the `andrewconnor1970.github.io` repository, preserving folders. Replace matching files.

## This release

- Adds the homepage **New at Tiamat** panel for Book Two and Else Artwork.
- Retains the five heads as the primary site structure.
- Includes current metadata, canonical URLs, social-preview metadata, structured data, favicon, robots file, sitemap, and custom 404 page.
- Includes the Else artwork gallery and its two image assets.
- Leaves a clearly marked insertion point before `</body>` for the site-specific Cloudflare Web Analytics snippet.

The previous partial CSS append files and navigation replacement notes are obsolete and are intentionally not included in this release.
